How do you submit a game or translation?

  1. Make sure that the game you are submitting is not already available in the archive, or is already going to be added in the next archive update.
  2. Send an e-mail containing the name of the fangame, the version number (if there is one), the original language the fangame was made in, the language it has been translated to (if you are submitting a fan translation), and the download link. It is also worth sending any documentation about the game, such as links to wiki articles about the game or the game's official website.
    • You can also submit a game or translation through the Discord server in #ynfg-archive channel.
  3. I will then verify that the files you send me are correct and add them into the next archive update.
